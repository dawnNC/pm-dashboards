# Feature Launch Gate

> No feature ships until all items below are checked. This applies to GA releases; Labs / early access may have a lighter gate (mark items N/A with justification).

## Pre-Launch Checklist

### Product
- [ ] PRD finalized and approved
- [ ] Acceptance criteria defined and verified
- [ ] Edge cases documented
- [ ] Rollback plan exists

### Engineering
- [ ] Implementation plan reviewed
- [ ] Code reviewed and merged
- [ ] Feature flag in place (if applicable)
- [ ] No P1/P2 open bugs

### Analytics
- [ ] Success metrics defined
- [ ] Tracking/events implemented and verified
- [ ] Dashboard exists or is linked
- [ ] Baseline captured pre-launch

### Documentation & Enablement
- [ ] Release notes drafted
- [ ] Help content updated (if user-facing)
- [ ] Sales / CS enablement notified
- [ ] Support team briefed

### Confluence (PRH)
- [ ] Feature page exists in PRH
- [ ] Customer-facing description written
- [ ] Known limitations documented

## Labs / Early Access Gate (lighter)
- [ ] Feature flag enabled for target accounts only
- [ ] Feedback collection method defined
- [ ] PM point of contact designated for escalations
- [ ] GA criteria defined upfront

## Post-Launch
- [ ] Metrics reviewed at 1 week
- [ ] Customer feedback collected at 2 weeks
- [ ] Retrospective scheduled (if major feature)
